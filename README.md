# iasEvent

1. Transfère le ZIP, puis fais clic droit → Extraire tout. Ouvre le dossier controle_tango_v2.
2. Installe Python 3.12 depuis le site officiel Python. Si le gestionnaire Python est déjà installé, utilise :py install 3.12
3. Double-clique sur Installer_V2_Windows.cmd. Cette installation se fait une seule fois et nécessite Internet pour télécharger les dépendances.
4. Double-clique sur Lancer_V2_Windows.cmd. Le navigateur du PC s’ouvre automatiquement sur l’interface locale.
5. Dans « Mes fichiers », sélectionne l’entrée Kafka et la sortie SID, puis lance le contrôle. Le mapping et les schémas sont déjà inclus.
